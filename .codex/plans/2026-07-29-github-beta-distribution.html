Logic and Data Flow

reviewed tag
  → no-secret validation/tests
  → protected beta signing key
  → signed local release
  → local verification
  → GitHub draft
  → remote-byte verification
  → public prerelease
  → anonymous install smoke test
Flow notes

State Model

OwnerStateLifecycle and authority
Git tagExact source commit and numeric versionCreated before dispatch; must be reachable from main. It is the immutable source identity.
GitHub EnvironmentBeta signing secret and approvalSecret exists outside the checkout and is readable only after environment protection succeeds.
Workflow runQueued → validating → testing → signing → drafting → verifying → publishing → smoke-testedTransient orchestration state. Logs contain paths/digests, never private-key bytes.
GitHub ReleaseAbsent → draft prerelease → public prereleaseDraft persists on upload/remote verification failure. Published assets are immutable and reconciled forward with a new version.
Installed betaCLI/server version and pinned beta authorityConsumers explicitly opt into a GitHub prerelease. The beta authority is retired at stable release rather than silently becoming production trust.
State notes

UI States and Transitions

No TinyHost-owned UI is planned. GitHub’s Actions and Releases pages are the operator UI.

StateOperator-visible behaviorTransition
Waiting for approvalWorkflow shows the protected beta-release environment gate.Required reviewer approves or rejects; no signing secret is exposed while waiting.
BusyNamed steps expose validation/build/verify progress without secret material.Linear step completion; cancellation before release publication leaves no public release.
Draft failureA draft release and failed step remain visible for diagnosis.Operator deletes the draft only after review, fixes source, and uses a new run/version when bytes changed.
SuccessGitHub shows a prerelease badge, assets, notes, and install commands.Consumers explicitly install from the versioned URL; no stable/latest promotion occurs.
