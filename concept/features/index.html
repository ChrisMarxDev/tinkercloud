Ranking rule

A capability moves upward only when it strengthens the protected deployment loop, removes a demonstrated operator/deployer obstacle, or has usage evidence. Features that broaden the runtime move downward unless their isolation and recovery cost is independently funded.

Scores use a 1–5 scale. Re-rank when base behavior ships or evidence changes.
