Ranked by secure user value, not novelty.

Only unimplemented or materially incomplete work belongs here. Implemented V1 foundations remain linked from the main concept but no longer occupy ranking slots. Yield is practical impact relative to complexity and risk.

Ranking rule

A capability moves upward only when it strengthens the protected deployment loop, removes a demonstrated operator/deployer obstacle, or has usage evidence. Features that broaden the runtime move downward unless their isolation and recovery cost is independently funded.

Secure gateway, control plane, immutable deployment, browser SDK, KV, local blobs, realtime, global viewer identity, CLI credential reuse, dashboard project controls, and agent skills are implemented foundations. They remain release-gated by their contracts and tests but are not planned-feature rows.

Scores use a 1–5 scale. Re-rank when base behavior ships or evidence changes.
